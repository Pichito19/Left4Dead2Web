# Proyecto: Left 4 Dead 2 - Página Web sobre Personajes y Zombies

## Descripción

Este proyecto es una página web dedicada al juego **Left 4 Dead 2**, un juego de disparos en primera persona desarrollado por Valve. La página está diseñada para mostrar detalles sobre los personajes principales del juego y los diferentes tipos de zombies que los jugadores deben enfrentar durante las campañas.

**Objetivo**: Crear una página web informativa para los fanáticos del juego, proporcionando descripciones de los personajes jugables y las criaturas (zombies) que habitan en el mundo de *Left 4 Dead 2*.

## Características

- Información sobre los personajes jugables: cada uno tiene una breve descripción, su historia y habilidades.
- Descripción de los diferentes tipos de zombies: Infectados comunes y especiales, sus características y comportamientos.
- Diseño atractivo y responsive usando **HTML** y **CSS**.
- Interactividad básica para navegar entre las secciones del juego.

## Tecnologías Utilizadas

- **HTML**: Para la estructura y contenido de la página.
- **CSS**: Para el diseño y el estilo visual de la página.
- **JavaScript** (opcional): Para posibles interacciones dinámicas (si se ha implementado).
